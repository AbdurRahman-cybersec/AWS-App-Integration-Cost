📖 Key Concepts

Three mental models for app integration and cost management

💬 Pub/Sub vs Point-to-Point Messaging

Pub/Sub = one message goes to many receivers. Point-to-point = one message goes to exactly one receiver.

DimensionPub/Sub (SNS, EventBridge)Point-to-Point (SQS)
How it worksOne sender, many receivers get copiesOne sender, one receiver processes it
Use caseFan-out: notify email + SMS + Lambda at onceDecouple services with a queue buffer
AWS servicesSNS, EventBridgeSQS
ExampleNew user signup → email + SMS + SlackOrder placed → one worker picks it up

💡 Event-Driven vs Workflow Orchestration

Event-driven = each service reacts to events independently. Workflow = a defined sequence of steps with retries and branching.

DimensionEvent-Driven (EventBridge)Workflow (Step Functions)
StructureLoose coupling — events trigger reactionsState machine — each step is explicit
VisibilityHard to trace end-to-endVisual execution history, clear state
RetriesYou build retry logic yourselfBuilt-in retries, timeouts, error branching
ExampleFile uploaded → trigger 3 independent lambdasOrder workflow: validate → charge → ship → notify

💰 Cost Visibility vs Cost Control

Visibility = see where your money went. Control = set limits and get alerts before you overspend.

DimensionCost Visibility (CUR, Cost Explorer)Cost Control (Budgets, Billing Conductor)
What it doesShows you what you spent and whySets limits and alerts before you overspend
AWS servicesCost Explorer, Cost & Usage ReportBudgets, Billing Conductor
GranularityHourly/daily, per-service, per-tagMonthly/quarterly budget thresholds
Example"EC2 costs spiked 30% this week — why?""Text me if spending hits $500 this month"
